# Roadmap

这里只记录明确的后续方向，不表示功能已经实现。

## 1.1 — 可维护的公开作品

- [x] 状态与逾期筛选，任务排序，视图偏好。
- [x] 导入格式校验和浏览器恢复快照。
- [x] CI、静态演示构建、贡献文档和项目模板。

## 下一阶段候选项

- [ ] 自动化浏览器回归：任务创建 → 移动 → 导出 → 恢复。
- [ ] 拆分界面渲染模块，减少整块重绘并保留键盘焦点。
- [ ] 本地撤销历史，支持撤销编辑和状态变更。
- [ ] 自定义项目与标签，提供向后兼容的数据迁移。

## 需要单独设计的能力

账号认证、共享工作空间、服务端授权、实时协作和附件存储。实现前先确定权限、数据隔离和部署方式，避免把单机 Demo 直接当作团队服务。
